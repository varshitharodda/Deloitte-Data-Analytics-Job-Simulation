# 🚀 Project Overview

This repository contains my work completed during the **Deloitte Data Analytics Job Simulation** offered through Forage.

The simulation focused on solving real-world business problems using **data analytics, forensic technology, Tableau dashboards, and Excel-based analysis**.

- Explored machine downtime patterns
- Created visual reports for decision-making

Built a Tableau dashboard to:
- Identify downtime trends
- Detect operational inefficiencies
- Visualize machine performance metrics
